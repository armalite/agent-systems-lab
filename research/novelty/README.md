# Novelty Gate Reviews

One file per research question: `RQ-001.md`, `RQ-002.md`, ...

The gate (`SPEC.md` s3, `AGENTS.md` s3) is mandatory before implementing any research programme
beyond calibration. It is a research gate, not documentation.

Each review must record:

- the exact research question;
- the hypothesis, if hypothesis-driven;
- why the answer would matter;
- what existing work appears closest;
- what this experiment adds that existing work does not;
- what result would be interesting even if the hypothesis is false;
- the sources actually searched, **at the time of the review**, with dates.

Decision, recorded explicitly: **Proceed / Narrow / Reframe / Stop**.

Two standing rules:

- Novelty is time-sensitive. Search current sources (arXiv, ACL/EMNLP/NAACL/NeurIPS/ICML/ICLR,
  lab research publications, benchmark repositories, credible systems work). Never rely solely
  on a model's internal knowledge.
- `SPEC.md` describing a direction is **not** evidence that the direction is novel.

---

*No novelty reviews recorded.* Phase 0 is calibration and does not require one; the gate applies
before the first frontier question is selected at Research Gate 1.
